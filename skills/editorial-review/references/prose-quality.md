# Prose Quality Reference

Apply these principles when evaluating prose craft. Flag specific passages that violate them.

## The Kansas City Star Rules

Hemingway called these "the best rules I ever learned for the business of writing."

1. **Use short sentences.** Long sentences lose readers. If a sentence needs a second read, it's too long.
2. **Use short first paragraphs.** Lead with impact. Don't warm up.
3. **Use vigorous English.** Active voice. Strong verbs. No passives hiding the actor.
4. **Be positive, not negative.** Say what something IS, not what it ISN'T. "He was silent" not "He did not say anything."
5. **Eliminate every superfluous word.** If removing a word doesn't change meaning, remove it.
6. **Avoid extravagant adjectives.** "Splendid", "gorgeous", "magnificent", "tremendous" — these are empty calories. Flag them.
7. **Use precise language.** "Died of heart disease" not "died of heart failure" — everybody dies of heart failure. Specificity = credibility.

## Paul Graham: Write Simply

- Simple prose requires less energy from readers, letting them focus on IDEAS not DECODING.
- Complex language masks lack of substance. Simple language keeps writers accountable — if there's nothing to say, it shows.
- Simple writing respects readers. Fancy writing forces them to do unnecessary work.
- Simple writing ages well. Ornate prose dates quickly.
- Simplicity requires deliberate revision — write fast, then spend time cutting.

## Paul Graham: Write Like You Talk

The test: read each sentence and ask "Is this the way I'd say this to a friend?" If not, rewrite it.

- If you just write in spoken language, you'll be ahead of 95% of writers.
- Read drafts aloud. Fix everything that doesn't sound like conversation.
- Fix phonetically awkward passages too — they interrupt flow even if logically fine.
- Spoken language disallows the worst kinds of writing: pompous abstractions, passive hedging, throat-clearing.

## Common Prose Failures to Flag

| Pattern | Example | Fix |
|---------|---------|-----|
| Throat-clearing opener | "It is important to note that..." | Delete. Start with the point. |
| Passive hedging | "It could be argued that..." | Who argues it? Say so, or own it. |
| Zombie nouns (nominalizations) | "The utilization of..." | "Using..." |
| Weasel words | "Some experts say..." | Which experts? Cite them or drop it. |
| Redundant pairs | "Each and every", "first and foremost" | Pick one. |
| Empty intensifiers | "Very unique", "extremely important" | Cut the intensifier or find a stronger word. |
| Corporate filler | "In terms of", "with respect to", "going forward" | Delete or replace with plain English. |
| Jargon without explanation | "We need to leverage our synergies" | Say what you mean in plain English. |
| Run-on qualifications | "...which, in and of itself, given the circumstances..." | Break into shorter sentences. |
| Abstract where concrete works | "There are challenges in the space" | Name the challenges. Name the space. |

## Filler-Phrase Substitutions

Mechanical swaps. Apply on sight.

| Filler | Replace With |
|---|---|
| In order to | To |
| Due to the fact that | Because |
| At this point in time | Now |
| In the event that | If |
| Has the ability to | Can |
| For the purpose of | To |
| In the process of | (delete) |
| It is important to note that | (delete) |
| It should be remembered that | (delete) |
| It goes without saying that | (delete — if it goes without saying, don't say it) |
| With respect to / In terms of | About / On |
| In light of the fact that | Because |
| A large number of | Many |
| The majority of | Most |
